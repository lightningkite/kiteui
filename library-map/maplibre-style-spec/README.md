Inputs to the `generateMapLibreLayerTypes` task:

- `v8.json`: the MapLibre style spec, from https://github.com/maplibre/maplibre-style-spec (see `LICENSE.txt`).
- `style-spec-cocoa-conventions-v8.json`: MapLibre Native's renames of style spec properties on iOS, from
  https://github.com/maplibre/maplibre-native/blob/main/platform/darwin/scripts/style-spec-cocoa-conventions-v8.json
